학습 순서

SQL은 한 번에 외우는 언어가 아니라, 작은 조회를 반복하면서 문장 구조를 익히는 언어입니다. 이 튜토리얼에서는 먼저 행과 열을 고르고, 조건을 붙이고, 정렬한 뒤, 여러 테이블을 연결하고 집계하는 순서로 진행합니다.

데이터 모델

주요 테이블은 students, teachers, classes, courses, scores, clubs, club_members, books, book_loans입니다. 컬럼명은 실제 수업 자료와 맞추기 위해 한국어를 사용합니다.
